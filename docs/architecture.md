# Aiham-UoU Architecture

## Product
Private communication application with temporary messages, video calls, and owner administration.

## Stack

Mobile:
- Flutter + Dart
- Riverpod state management
- Clean Architecture
- Feature based structure

Backend:
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Messaging
- Cloud Functions

Realtime:
- WebRTC using flutter_webrtc
- Firestore based signaling for initial version

Admin:
- React + TypeScript dashboard

## Initial Features

- User accounts
- Private conversations
- Temporary messages
- Push notifications
- One-to-one audio/video calls
- Owner control panel

## Principles

- Scalable structure
- Security first
- Low operating cost
- Professional UI/UX
